# project-from-idea

Turns a rambling "I want to start X" into a scoped project note, or says it is too small
to be one.

## SKILL.md

```markdown
---
name: project-from-idea
description: Use when the user dumps an unstructured idea for something new they want to build - a rambling pitch, a goal they have not scoped. Turns it into a project note instead of leaving it loose in a scratch file.
---
```

## Procedure to write into the body

1. **Read the project template and schema** first, so the note matches the rest.
2. **Check before creating:** existing projects and archives that already cover it, whether
   it is really a new phase of an existing project, and any scratch note on the same idea
   to fold in rather than duplicate.
3. **Extract from the dump, do not invent past it:** a working title, a status (not
   started unless they say it is underway or blocked), a start date if they are starting
   now, a target date only if they gave one, and tags that match existing conventions.
4. **Multi-stage ideas** become Phase 0, 1, 2 with checkbox items and one deliverable per
   phase, not a wall of prose.
5. **Flag, do not resolve,** anything ambiguous.
6. **Propose the full draft and wait for a yes** before creating the file.

## Rule

Not every idea is a project. A small bounded task belongs on a to-do list; a project
implies multi-session scope. Say so when the dump reads as the smaller kind.
